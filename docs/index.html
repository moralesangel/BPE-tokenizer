BPE Tokenizer

A 3,000-token vocabulary trained from scratch on short stories. Source and training notebook →

1. Tokens

Text is split into words, each gets a </w> end marker, then merge rules fire. Chips are grouped by word; orange means the piece was not in the vocabulary and fell back to characters.

2. How one word gets built

Every rule is applied in the order it was learned during training. Only the rules that actually changed this word are shown.

3. Decoded back

Ids → tokens → text. Case is lost because training lowercases everything.

Runs entirely in your browser — vocabulary and merge rules are the same files the Python tokenizer loads.
